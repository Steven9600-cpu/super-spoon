Get started

  1. Fork the repository and clone it locally.
  2. Install dependencies: npm install or check README.md for language-specific steps.
  3. Run the development server: npm start (or see README).
  4. Open an editor and look at src/ and docs/ for architecture notes.

  • Read the CONTRIBUTING.md (if present).
  • Pick an issue labelled good first issue or help wanted.
